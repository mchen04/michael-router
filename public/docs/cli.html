CLI reference

Use mrouter to send prompts, check usage, and manage the router.

Install and log in

Use Node.js 24. Set the URL before your first login, then enter your router password at the hidden prompt.

The download is the CLI package. Login checks the password before saving it. It accepts no password argument or password flag.

Configuration

The URL comes from --url, then MROUTER_URL, then the saved configuration. A trailing /v1 is accepted.

The password comes from MROUTER_PASSWORD, then the saved credential. A saved password only goes to its saved URL.

Use HTTPS. HTTP is accepted only for localhost, 127.0.0.1, or [::1]. URLs cannot contain credentials, a query, or a fragment.

Files live in $XDG_CONFIG_HOME/michael-router/, or ~/.config/michael-router/ by default. The directory uses mode 0700; files use 0600.

config.json holds the URL. credentials holds the password. Never share or commit the credential file.

Global flags

--url URL
Set the router URL for this command.
--json
Print JSON output. For streaming ask, return the assembled chat completion.
--timeout S
Set 0.1–3600 seconds. Defaults: 30 for control commands, 300 for ask and test, including streams.
--no-color
Disable color. NO_COLOR also disables it.
-h, --help, --version
Show help or the installed version.

Global flags can go anywhere. Put command flags after the command. Use -- to end flag parsing.

Every command

Provider names are claude, openai, gemini, and openrouter.

login [--url URL]

Read the password from a hidden prompt or stdin. Check it with the server, then save the URL and password.

logout

Delete the stored password. MROUTER_PASSWORD still takes precedence if set.

status

Show the URL, password status, and config paths without contacting the server or printing the password.

health

Show the version, region, store status, latency, and configured providers.

keys list

Show each provider’s configuration, key source, and last update. Never print key values.

keys set <provider> [--no-verify]

Read the provider key from a hidden prompt or stdin. Verify it before storing an encrypted override. A rejected key never replaces the current key. Use --no-verify only to skip that check.

keys unset <provider>

Remove the stored override. The provider falls back to its deployment environment key.

models

List known models for configured providers, with context and output limits when known.

ask [-m MODEL] [-s SYSTEM] [--no-stream] [--max-tokens N] [--show-reasoning] [PROMPT...]

Stream a reply to stdout and usage to stderr. The default model is gemini-3.5-flash-lite. Piped stdin is appended to the prompt. Use </dev/null when a noninteractive caller leaves stdin open. Reasoning stays hidden unless --show-reasoning is set.

test [provider...] [-m MODEL]

Send one regular and one streaming request per configured provider. Use -m to test one model. Failed checks do not stop the remaining checks.

usage [--days N | --since YYYY-MM-DD]

Show usage and cost per provider and model. The default is 30 days; the limit is 400 days. Partial cost is a lower bound.

errors [--limit N] [--kind auth|upstream|gateway]

Show recent error and authentication events, newest first. The limit is 1–200, with a default of 50.

hash-password

Read a new password from a hidden prompt or stdin. Print a ROUTER_PASSWORD_HASH value for the deployment. Passwords need at least 12 printable ASCII characters, without surrounding spaces.

help [command]

Show command help. The --help flag does the same.

Exit codes

0 · Success
The command completes.
1 · Router or platform error
Check the response and request ID.
2 · Usage error
Fix arguments, input, URL, or missing credentials.
3 · Authentication or rate limit
Stop on 401. On 429, wait for Retry-After.
4 · Provider error
Check the provider, key verification result, or failed smoke test.
5 · Network or incomplete stream
Check connectivity. A stream without [DONE] is incomplete.
130 · Cancelled
The user presses Ctrl-C at a prompt.

Secret handling

Passwords and provider keys come from hidden prompts or stdin, never command arguments. The CLI does not follow redirects.

Logs and error output scrub secrets. Streamed model output is returned as received. Do not ask a model to print credentials.
