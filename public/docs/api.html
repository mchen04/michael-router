Connection and authentication

Base URL
https://michael-router.vercel.app/v1
Authentication
Authorization: Bearer <router password>

Read the password from MROUTER_PASSWORD. OpenAI SDKs send the Bearer header when you set their API key.

Every API route requires the password. Provider keys stay on the server. x-api-key and Basic authentication do not work.

The API does not send CORS headers. Use a server-side client, not browser JavaScript.

Endpoints

POST /v1/chat/completions
Send model and messages. Add stream: true to stream the reply.
GET /v1/models
List known models for configured providers. Context length and maximum output appear when known. This list is not exhaustive.
GET /control/health
Check the server, store, and configured providers.
/control/keys
List keys with GET. Set or remove a provider override with PUT or DELETE at /control/keys/:provider.
GET /control/usage
Get usage with ?days=N or ?since=YYYY-MM-DD, up to 400 days.
GET /control/errors
Get recent events with ?limit=N and optional kind=auth|upstream|gateway.

Model routing

The first matching rule wins. IDs contain 1–128 letters, digits, or ._:/@+-, and start with a letter or digit.

  1. IDs containing / go to OpenRouter. Only :free IDs and openrouter/free are allowed. Paid IDs are refused.
  2. claude-* goes to Claude.
  3. gpt-* and reasoning IDs such as o3 or o4-mini go to OpenAI.
  4. gemini-* goes to Gemini.

Other IDs fail with model_not_routable. See Providers and models for the full catalog and examples.

Streaming

Set stream: true. The response uses text/event-stream and OpenAI chat completion chunks.

Read text from choices[0].delta.content. Skip empty choices arrays, which can contain usage.

Add stream_options: {"include_usage": true} to request usage. A complete stream ends with data: [DONE].

A stream can fail after HTTP 200. An error event or a missing [DONE] means the response is incomplete.

Claude translation

Send OpenAI messages and function tools. The router translates them to Anthropic’s Messages API and returns OpenAI-format responses.

Use response_format: json_schema for structured output. json_object has no equivalent and is refused.

Pass Claude-specific fields through extra_body={"anthropic": {...}} in Python, or anthropic in the JavaScript request.

Automatic prompt caching is enabled. Send x-router-cache: off to disable it for one request.

Leave anthropic.thinking off in tool loops. Chat Completions cannot return signed thinking blocks to Claude on later turns.

Errors and recovery

Read error.code and error.message. The error type is gateway_error or upstream_error.

Upstream errors include the provider and, when available, upstream_status. Keep x-router-request-id when asking for help.

400 · Invalid request
Fix JSON, model ID, message shape, or unsupported fields before retrying. Codes include invalid_json, model_required, invalid_model, model_not_routable, invalid_parameter, unsupported_parameter, unsupported_content, and invalid_tool_arguments.
401 · Router password
Stop. Correct the missing or invalid password. Repeated failures cause a delay and then block the source.
402 / 403 · Provider billing or access
Ask the router owner to fix billing or access. Do not retry unchanged.
404 / 405 · Path or method
Fix the endpoint or method. Authentication happens before these errors.
413 · payload_too_large
Reduce the body below 4 MiB for chat or 16 KiB for control requests.
429 · Wait before retrying
Wait for Retry-After. Codes include auth_backoff, source_blocked, auth_busy, and provider_rate_limited.
500 · internal_error
Retry with backoff. Report repeated failures to the router owner.
502 · Provider failure
For provider_auth_failed, ask the owner to fix the provider key. Do not change the router password. Retry provider_error or upstream_unreachable with backoff.
503 · Configuration or store
For provider_not_configured, ask the owner to configure that provider. For server_misconfigured, ask the owner to fix deployment settings. Retry store_unavailable with backoff.
504 · upstream_timeout
The 295-second limit expired. The provider may already have billed the work. Check before retrying.

Usage and limits

Usage is recorded per UTC day, provider, and model. Cost can be exact, estimated, unknown, mixed, or partial.

A partial cost is a lower bound. Missing prices or usage do not count as zero cost.

The request body limit is 4 MiB. The provider timeout is 295 seconds, including streams. Disconnecting cancels the upstream request.
