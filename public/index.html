Use the same URL and password for all four providers.

Start with your password

Set MROUTER_PASSWORD in your local environment to the router password you received.

The examples read this variable. Never paste your password into this page or share it in code.

  1. Set your client’s base URL to https://michael-router.vercel.app/v1.
  2. Use the router password as the API key. The client sends Authorization: Bearer <password>.
  3. Choose a model below and send your first message.

Python and JavaScript examples use the openai package. CLI examples require Node.js 24 and mrouter.

Prefer the terminal?

Install mrouter from a checkout of github.com/mchen04/michael-router with npm install -g ..

Use the environment variable above, or run mrouter login --url https://michael-router.vercel.app/v1 for a hidden password prompt.

If a request fails

A 401 means the router password is missing or incorrect. Check your password before trying again.

A 429 means you must wait before retrying. A 502 or 503 may need the router owner’s help.
