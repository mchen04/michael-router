# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The owner's developer friends already have the shared password. They want to send a first request without learning another API.

## Product Purpose

Michael Router provides one private OpenAI Chat Completions endpoint for four providers.
Success means a visitor makes a working first request in under a minute.

## Operating Context

Visitors configure a client or terminal with OPENAI_BASE_URL and OPENAI_API_KEY.
The password is supplied privately. The public site never accepts or displays a real credential.

## Capabilities and Constraints

The model ID selects Claude, OpenAI, Gemini, or free OpenRouter models.
Only the supplied models tested on 2026-10-29 appear publicly.
Each provider has a recommended default and one copyable request.
The API guide explains connection, routing, streaming, and recovery.
The catalog lists tested models. The agent guide gives short instructions.
No public owner tools, deployment details, or control routes appear.
Static HTML, CSS, and JavaScript use no external requests or dependencies.
The existing security headers and CSP remain intact.

## Brand Commitments

Use the name Michael Router. Write in plain, short sentences.

## Evidence on Hand

The owner supplies the tested model catalog and authentication contract.
No testimonials, performance claims, or invented social proof are available.

## Product Principles

Make connection details immediately useful.
Show only tested choices.
Keep each document responsible for one job.
Preserve the password boundary.

## Accessibility & Inclusion

Support 360px screens, keyboard navigation, visible focus, light and dark themes, and AA contrast.
Use local system font stacks. Do not load web fonts or remote images.
